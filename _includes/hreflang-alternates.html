{%- comment -%} Emits reciprocal hreflang alternates for a multilingual post. Translations come from post-translations.html (same category + slug, with the per-language category segments applied), so basename collisions in different categories are NOT falsely paired and an untranslated post links only to itself. x-default policy: ko (domestic primary) > en > ar. Usage (inside a sitemap block): {% include hreflang-alternates.html url=post.url %} {%- endcomment -%} {%- include post-translations.html url=include.url -%} {%- if tr_ko != '' %} {% endif -%} {%- if tr_en != '' %} {% endif -%} {%- if tr_ar != '' %} {% endif -%} {%- if tr_ko != '' -%}{%- assign _xdef = tr_ko -%}{%- elsif tr_en != '' -%}{%- assign _xdef = tr_en -%}{%- else -%}{%- assign _xdef = tr_ar -%}{%- endif -%} {%- if _xdef != '' %} {% endif -%}
