{% comment %} Post-footer tags, rendered as plain text rather than links. There is no per-tag archive page any more — tag filtering lives on the Posts page — and the previous markup piped the whole URL through `slugify` (`path_type | append: tag_word | slugify`), which mangled "/en/?tags=vllm" into dead paths like "/en-tags-vllm". Plain text removes the broken links. Tags are looked up in site.data.tag_labels so a tag written in one language's frontmatter (e.g. Korean tags on an EN/AR post) still displays in the reading post's own language.
