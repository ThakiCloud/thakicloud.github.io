{% comment %} Breadcrumbs for the consolidated site structure. Categories/Tags/Comics pages were merged into the language home, which is now the single Posts page and filters in place via ?category=. So the crumbs are: Home -> /{lang}/ (that language's Posts page) Dev -> /{lang}/?category=dev (same page, filtered) title -> current page The old build walked page.url segments and pointed the middle crumb at /{lang}/categories/#{cat}, which no longer exists. It also emitted a separate language crumb, but "/" just redirects to /{lang}/, so that duplicated Home.
