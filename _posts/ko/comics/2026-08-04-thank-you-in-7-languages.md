이 영상은 한국어, 영어, 일본어, 중국어, 프랑스어, 러시아어, 아랍어 일곱 가지 말로 고맙다는 인사를 배우는 아이용 짧은 수업입니다. 각 언어는 그 나라 원어민 목소리로 두 번씩 천천히 들려줘서 따라 말하기 쉽습니다. 아이 옆에 앉아 한 마디씩 같이 따라 해 보면 좋습니다. 하루 만에 일곱 나라 인사말이 입에 붙습니다.

**영상판 - 오늘의 한마디를 각 언어로 들어봅니다**

각 언어는 원어민 음성으로 두 번씩 나오고, 한국어 자막이 함께 나갑니다.

| 언어 | 표기 | 발음 |
|---|---|---|
| 한국어 | **고맙습니다** | 고-맙-습-니-다 |
| 영어 | **THANK YOU** | 땡-큐 |
| 일본어 | **ありがとう** | 아리가토- |
| 중국어 | **谢谢** | 씨에-씨에 |
| 프랑스어 | **MERCI** | 메르-시 |
| 러시아어 | **СПАСИБО** | 스파-시-바 |
| 아랍어 | **شكرا** | 슈크-란 |

**이럴 때 씁니다**

- **한국어**: 우리말로는 고맙습니다 라고 말해요.
- **영어**: 영어로는 땡큐 라고 말해요.
- **일본어**: 일본에서는 아리가토 라고 말해요.
- **중국어**: 중국에서는 씨에씨에 라고 말해요.
- **프랑스어**: 프랑스에서는 메르시 라고 말해요.
- **러시아어**: 러시아에서는 스파시바 라고 말해요.
- **아랍어**: 사우디에서는 슈크란 이라고 말해요.

## ThakiCloud 제품 적용 시사점

교육 콘텐츠를 언어마다 새로 만들면 비용이 언어 수만큼 불어납니다. 이 영상은 장면을 한 번만 만들고 음성과 자막, 화면 글자만 언어별로 바꿔 끼우는 구조라 언어 하나를 더 넣는 부담이 거의 없습니다. 같은 방식을 사내 자료에 적용하려면 다국어 음성 모델을 어디서 돌리는지가 관건입니다. Metis에서 파인튜닝하고 서빙하면 학습 데이터와 아이들 목소리가 사내 클러스터 밖으로 나가지 않습니다. 밖으로 내보내기 어려운 데이터를 다루는 조직일수록 온프렘 주권형 구성이 실제 차이를 만듭니다.
